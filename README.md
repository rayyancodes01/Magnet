# 💊 MAGNET Pharmacy | Erandol

**Live Link:** https://rayyan-store.vercel.app

A modern online pharmacy platform built for local medical stores. Customers can order medicines, upload prescriptions, and get home delivery in Erandol.

### ✨ Key Features
- 🔍 Smart Medicine Search
- 📄 Prescription Upload
- 🛒 Add to Cart & Checkout
- 🏥 Healthcare Categories
- 📱 Fully Responsive (Mobile + Desktop)
- ⚡ Fast & Lightweight

### 🛠️ Built With
- React + TypeScript
- Tailwind CSS
- Vercel Hosting
- GitHub
